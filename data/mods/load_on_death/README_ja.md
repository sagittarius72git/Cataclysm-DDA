# 死亡時ロード（CDDA 0.I）

Cataclysm: DDA 安定版 0.I-1（Ito-1）用のMODです。死んだとき、代わりに最後のセーブへ戻れます。JSON（EOC）だけで動きます。

## 動き

- 死亡画面のあとに「この死を取り消して、最後のセーブに戻りますか？」と聞かれます。
- はい：死亡が保留になります。デバッグメニューの「ゲーム...」→「クイックロード」で最後のセーブを読み込みます。
- いいえ：通常どおり死亡します。

## 準備

デバッグメニューには初期キーがありません。最初に一度だけ、Escメニュー →「キー割当」→「デバッグメニュー」にキーを設定してください。
CDDA のリリース版にはクイックロードのキーが無く、JSON MOD からロードを始めることもできないため、デバッグメニューを使います。デバッグメニューのクイックロードでは実績は無効になりません。

## 注意

- 戻れるのは存在するセーブだけです。一度もセーブしていないキャラクターはロードできません。
- 死亡保留中に5秒経つと再び死亡し、同じ質問が出ます。
- 死亡保留中に作られたセーブ（セーブして終了、またはちょうどその時のオートセーブ）は、ロード時に死亡します。
- 他MODの蘇生（PREVENT_DEATH）が先に試されます。仲間がいる場合は本体の「仲間の一人を選んでゲームを続けますか？」が先に出ます。
- 既存のワールドに追加できます。
